# Valkyria alternate logo direction

This is a separate, more minimal direction alongside the shield-and-wings logo family in `../`. It uses a split-spear V and a directional yellow point to suggest precision and choosing a route. The letterforms are uppercase and more typographic. The original family remains untouched.

| Mark | Dark theme | Light theme |
|---|---|---|
| Primary wordmark | `primary-dark.svg` | `primary-light.svg` |
| CLI subbrand | `cli-dark.svg` | `cli-light.svg` |
| Standalone symbol | `symbol-dark.svg` | `symbol-light.svg` |
| Compact submark | `submark-dark.svg` | `submark-light.svg` |

## Construction rules

- Use a one-third grid for horizontal lockups: the V symbol occupies the opening third, while the wordmark and CLI label use the remaining two-thirds.
- Keep clear space around the V equal to the width of its main stroke. For horizontal lockups, use that same measure around the full mark.
- Minimum sizes: primary wordmark 180 px wide; CLI lockup 220 px wide; symbol 24 px high; compact submark 18 px high.
- Pair the cloud mark with dark graphite surfaces and the graphite mark with light cloud surfaces. Keep sunshine yellow limited to the directional point and divider.
- Scale uniformly. Do not skew, rotate, outline the wordmark, add effects, or move the accent independently.
- At tiny sizes, use the compact submark. If the yellow point loses clarity, use a single-color version rather than enlarging or embellishing it.
